# Actividad-4
Seguir con una aplicación de juegos que maneja la física como inteligencia con un grado de dificultad aún mayor y requiere de cambios para hacer un juego más retador e interminable.
## Funcionalidades implementadas
- Se agregó que el juego nunca termine, de manera que los balones al salir de la ventana se re posicionen.
##Instrucciones de ejecución
1. Asegúrate de tener Python instalado y el paquete freegames:
pip install freegames
2. Ejecuta el juego:
python memory.py
