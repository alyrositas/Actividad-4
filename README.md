# Actividad-4

Seguir con una aplicación de juegos que maneja la física como inteligencia con un grado de dificultad aún mayor y requi... (aquí va tu descripción completa)

## Funcionalidades implementadas

- **Juego infinito:** Se agregó que el juego nunca termine, de manera que los balones al salir de la ventana se reposicionen.
- **Mayor velocidad:** Se aumentó la velocidad del movimiento del proyectil y de los balones.

## Instrucciones de ejecución

1. Asegúrate de tener Python instalado y el paquete `freegames`:

   ```bash
   pip install freegames
   ```

2. Ejecuta el juego:

   ```bash
   python cannon.py
   ```
